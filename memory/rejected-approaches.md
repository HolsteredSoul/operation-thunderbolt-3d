Each entry: **what** — **why not** — **revive only if**. Check this before proposing an
approach. Nothing leaves this list by being re-proposed; only by its revival condition.

- **A journal / narrative session log** — rots into write-only noise nobody reads back;
  history is `git log`, state is the Status pointer, lessons are Slips, decisions are memory
  — revive only if those four prove insufficient to reorient a session.
- **Harness hooks to enforce the session ritual** — the user prefers convention-enforced
  discipline via CLAUDE.md — revive only if the user asks, after the ritual has been skipped
  repeatedly.
